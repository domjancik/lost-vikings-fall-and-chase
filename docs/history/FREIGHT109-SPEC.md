# The Ember Freight

An incinerator freight depot burns rejected weather. The Vikings recover an
inspector's power cell and use the service circuit to purge the furnaces. Add this
as the eighth Machine Rooms level; preserve the current campaigns and art.

Concept comparison: Ember Freight provides active escort/combat and a legible
steam/rail/purge chain. Scrap Orbit risks opaque rotating collision. Thunder
Shepherd would repeat the rolling capsule rather than develop stronger combat.
Retain the Imagegen concept and exact prompt separately from native runtime art.
