# Native-density Vikings55

Built-in imagegen sources retain deliberately coarse flat shapes and adult
silhouettes. PROMPTS.md records generation and targeted edits. Earlier detailed
Vikings54 sources were rejected before publication; these are fresh replacements.

Erik:36native/72world standing height, lean rust scout, cream scarf, short ginger
beard. Baleog:38native/76world, upright teal warrior with shoulder plates, sword,
quiver and bow. Olaf:36native/72world, broad ochre defender with pale twin braids.
Body sheets512x256,8columns4rows of native64square padded cells. Shared body
origin32,40 and sole62. A single14x24native shield remains28x48world in both
states. Sources may be enlarged presentation files; their coarse detail density
is judged visually against intended gameplay size before packing.

Rebuild once from original: tools/prepare-vikings55.py. Registration metadata:
registration.json. Scale is uniform per character across all32frames; only sole
registration translates grounded poses. No repeated pack/resample chain. Any
neighboring detached cell fragment is rejected at the source component boundary.

Raw-source and processed/gameplay gate verdicts belong in CYCLE-REVIEW.md.
Use hero-art-preview.html for motions/mirroring/grayscale, then real game scenes
for final approval. Dimensions and alpha validation do not replace visual review.
