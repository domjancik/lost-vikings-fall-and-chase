# Middle architecture sources

Generated with built-in imagegen, transparent-background mode. Original sheets
are preserved as source-0.png and source-1.png. Each has four 768×512 panels.
Runtime sprites are prepared by tools/prepare-mid49.py; alpha is deliberately
binary to prevent ghostly architecture, and support edges are aligned without
stretching. Native sprites are 384×256, displayed at two world units per pixel.

Sheet 0 requested quiet, connected brass coin-return funnels; steel routing looms
with coral ribbons; ivory memory reeds on indigo beds; and sage ceramic world
manufacture with terracotta miniature molds. Each connects to a bottom foundation.

Sheet 1 requested copper archive racks, navy hanging canopy gills joined to a
top-edge ceiling girder, charcoal ownership memory banks, and wood/brass physical
pub marquee fittings. All except the canopy connect to bottom foundations.

Both prompts required complete side-view silhouettes, transparent empty space,
opaque structures, sparse negative space, muted colors, no lettering, characters,
fire, smoke, foreground gameplay platforms or interactive-looking controls.
